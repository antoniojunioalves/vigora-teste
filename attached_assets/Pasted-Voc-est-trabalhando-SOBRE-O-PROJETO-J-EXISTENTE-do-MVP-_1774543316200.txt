PARTE 1 — NOVA FUNCIONALIDADE: CONTATOS WHATSAPP
==================================================

Quero adicionar uma nova funcionalidade completa de cadastro de contatos WhatsApp.

CRIAR NOVA PÁGINA
- Criar uma nova página chamada “Contatos WhatsApp”
- Adicionar essa página na navegação do sistema
- O item deve aparecer de forma consistente com os outros módulos do app

OBJETIVO
Permitir cadastrar, listar, editar, excluir e buscar contatos WhatsApp que poderão ser vinculados a processos para notificações futuras.

ESTRUTURA DA TELA
A página “Contatos WhatsApp” deve conter:

1. Header da página
- título: “Contatos WhatsApp”
- subtítulo curto explicando o objetivo
- botão principal: “Adicionar Contato”

2. Área de busca e filtros
- campo de busca por nome ou número
- filtro por status: ativo / inativo / todos

3. Tabela ou lista principal
Colunas:
- Nome do contato
- Número de WhatsApp
- Email
- Status
- Data de criação
- Ações

Ações:
- Editar
- Excluir

4. Modal ou formulário de criação/edição
Campos:
- Nome do contato (obrigatório)
- Número de WhatsApp (obrigatório)
- Email (opcional)
- Status (ativo/inativo)
- Observações (opcional)

REGRAS E VALIDAÇÕES
- Nome é obrigatório
- Número é obrigatório
- Número deve aceitar formatos com ou sem +55
- Número deve ter pelo menos 10 dígitos úteis
- Número não pode ser duplicado
- Mostrar mensagens de erro amigáveis
- Ao salvar com sucesso, exibir toast visual
- Ao excluir, pedir confirmação antes

PERSISTÊNCIA
Se o projeto já estiver conectado ao banco, integrar os contatos WhatsApp ao banco real.
Se ainda estiver em mock/local storage, implementar na mesma estratégia atual do projeto, sem quebrar a arquitetura.

DADOS / MODELAGEM
Criar a estrutura necessária para contatos WhatsApp com campos equivalentes a:
- id
- nome
- numero_whatsapp
- email
- status
- observacoes
- created_at
- updated_at

PARTE 2 — NOVA FUNCIONALIDADE: VINCULAÇÃO WHATSAPP-PROCESSO
==================================================

Quero adicionar uma segunda funcionalidade: vincular um ou mais contatos WhatsApp a um processo.

CRIAR NOVA PÁGINA
- Criar uma nova página chamada “Notificações de Processos”
- Adicionar essa página na navegação do sistema

OBJETIVO
Permitir escolher um processo e associar múltiplos contatos WhatsApp a ele.

ESTRUTURA DA TELA
A página deve conter dois blocos principais ou uma estrutura equivalente bem resolvida:

BLOCO A — LISTA DE PROCESSOS
- Listar todos os processos já cadastrados no sistema
- Mostrar colunas:
  - Número do processo
  - Cliente
  - Status
  - Quantidade de contatos vinculados
  - Ação para gerenciar vínculos

- Permitir selecionar um processo para visualizar/editar vínculos

BLOCO B — CONTATOS VINCULÁVEIS
Quando um processo for selecionado:
- Exibir lista de contatos WhatsApp ativos
- Cada contato deve aparecer com checkbox
- Mostrar:
  - Nome
  - Número
  - Status
- Permitir seleção múltipla
- Botão “Salvar vinculação”

FUNCIONALIDADES
- Vincular um ou mais contatos a um processo
- Desvincular contatos de um processo
- Visualizar quais contatos já estão vinculados
- Editar vínculos existentes
- Exibir os contatos vinculados na listagem dos processos
- Permitir remoção rápida de um contato vinculado

INTERFACE RECOMENDADA
Na listagem principal, mostrar:
- Processo
- Cliente
- Status
- Contatos vinculados (chips/badges ou lista resumida)
- Botão “Gerenciar”

Ao clicar em gerenciar:
- abrir modal, drawer ou área lateral bem organizada
- mostrar o processo selecionado
- mostrar a lista de contatos com checkboxes
- marcar automaticamente os contatos já vinculados
- permitir salvar alterações

DADOS / MODELAGEM
Criar a estrutura de vinculação entre processos e contatos WhatsApp.

Modelo sugerido:
- id
- processo_id
- contato_whatsapp_id
- created_at

Regras:
- um processo pode ter vários contatos
- um contato pode estar vinculado a vários processos
- impedir duplicidade da mesma vinculação
